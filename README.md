## 🌟 Project Overview

**WebNova** is a modern concept landing page designed to demonstrate front-end development capabilities, responsive UI design, and interactive user experiences. Built with pure **HTML5**, **CSS3 (Flexbox & CSS Grid)**, and **Vanilla JavaScript**, it achieves high performance without reliance on heavy third-party UI frameworks.

## ✨ Key Features & Technical Highlights

### 1. 🧭 Navigation & Header
- **Logo & Branding:** Custom WebNova geometric icon with radiant blue-to-purple gradient.
- **Site Navigation:** Working smooth-scrolling links to `Home`, `About`, `Services`, `Why Choose Us`, `Projects`, `Meet Developer`, and `Contact Me`.
- **Sticky Glassmorphism:** Header with frosted blur effect (`backdrop-filter: blur(16px)`) and subtle elevation shadow on scroll.
- **Scrollspy:** Automatically highlights the active section in the navigation menu during scrolling.
- **Authentication Buttons:** Dedicated **Log In** and **Sign Up** action buttons in both the desktop navbar and mobile drawer.
- **Mobile Navigation:** Animated hamburger toggle that reveals a slide-out drawer with backdrop overlay and body scroll locking.

## 🚀 How to Run Locally

### Prerequisites
- Any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
- Visual Studio Code (recommended).

### Step-by-Step Instructions
1. **Clone the repository:**
   ```bash
   git clone https://github.com/satyam07-prog/WebNova-Landing-Page.git
   ```
2. **Navigate to the project folder:**
   ```bash
   cd WebNova-Landing-Page
   ```
3. **Run with VS Code Live Server:**
   - Open the folder in VS Code.
   - Right-click on `index.html`.
   - Select **"Open with Live Server"** (or click **"Go Live"** in the bottom status bar).
   - The site will launch at `http://127.0.0.1:5500/index.html`.
4. **Or open directly:**
   - Double-click `index.html` to open it in your default web browser.
